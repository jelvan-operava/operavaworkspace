# Operava Desk

Enterprise Google Workspace-style client portal built with **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS v4**, and **Material Design 3**. It provides omnichannel Zoho Desk-style ticketing, CRM annotations, scheduled email blasting, billing/invoicing, contracts, file management, calendar, analytics, security/audit logging, a knowledge base, and a server-side Gemini AI assistant, with offline-first PWA support.

## Quick Start

```bash
npm install
cp .env.example .env.local   # set GEMINI_API_KEY
npm run dev                  # http://localhost:3000
```
